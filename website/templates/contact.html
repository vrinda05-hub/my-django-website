About Student Task Manager

Student Task Manager is a web application developed using Python and Django to help students organize their daily tasks.

Our Purpose

The main purpose of this project is to make task management simple and efficient. Students can add tasks, view their tasks, mark them as completed or pending, and delete tasks when finished.

Technologies Used

Python, Django, HTML, CSS, and SQLite Database.
